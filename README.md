Данный скрипт позволяет анализировать данные о производительности сотрудников из CSV-файлов и формировать отчет, показывающий среднюю производительность по каждой должности.

В проекте есть README, .gitignore. Есть файл с зависимостями, линтер и форматтер. Проект разбит по модулям: app/, tests/, data/.

Используются аннотации типов. Используется ООП. Используются абстрактные классы для описания логики отчётов.

Используется dataclasses. Используется @pytest.fixture.

requirements.txt:

tabulate~=0.9.0 pytest~=7.4.0 flake8~=6.0.0 black~=23.7.0

Команда для установки зависимостей:

pip install -r requirements.txt

Создание и запуск виртуального окружения:

python -m venv venv venv\Scripts\activate

Запуск программы:

python main.py --files employees1.csv employees2.csv

Где:

--files — аргумент, указывающий входные CSV-файлы.

Вызов справки:

python main.py --help

Запуск тестов из корня проекта:

pytest tests/

Проект доведён до статуса Production-Ready (CLI) — проект готов к эксплуатации в рабочих процессах.

Архитектура и надёжность: реализация на принципах ООП с использованием абстрактных классов для описания логики отчётов; структурирование данных через dataclasses; применение контекстных менеджеров для гарантированной корректной работы с ресурсами; строгая типизация за счёт аннотаций типов.

Качество кода и поддерживаемость: модульная структура проекта; соблюдение единого стиля кода с помощью форматтера black; контроль качества кода через линтер flake8; наличие документации (README) и файла .gitignore.

Тестирование: покрытие функционала тестами на базе pytest; использование @pytest.fixture для подготовки тестовых данных; проверка краевых случаев и корректности обработки данных.

Интерфейс: управление через CLI с использованием argparse; поддержка передачи нескольких входных CSV-файлов; вывод отчёта в консоль.
